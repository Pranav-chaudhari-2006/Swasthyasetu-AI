## Service Specification Checklist

For every service introduced in the project, document:
- Service Name & Boundary
- Input / Output Contracts
- API Specifications & Authentication Requirements
- Database Access & Isolation
- Failure Handling & Fallback Behavior
- Integration Points & Consumers
